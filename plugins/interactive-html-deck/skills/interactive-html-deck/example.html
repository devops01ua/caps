Graph engine · 1 of 4

A document is indexed twice: once by its words, once by its meaning

Scenario. Someone saves a new page. A minute later both indexes know about it.
Graph nodes are [x, y, w, h, title, subtitle, cls, iconKey]. This example has no icon keys; to use official cloud icons, build an ICONS map with aws_icons.py and add the key as the 8th field. Edges are 'a>b'; add ~h or ~v to force the route.
MeaningMap engine · 2 of 4

Pages about the same topic sit close together, even when the words differ

What an embedding is. A model turns text into a list of numbers, a point on a "map of meaning".
The map is two-dimensional for the picture; real embeddings have hundreds or thousands of dimensions. Each step passes a full state: which points are on, their classes, positions and lines.
Lists engine · 3 of 4

Two ranked lists merge: full keyword matches stay first, a vote orders the rest

Scenario. The query "network policy blocks egress" goes to both searches at once.
The vote is reciprocal rank fusion: each page scores 1/(60 + rank) from each list and the scores add up. Each step passes {id: [column, row, cls]} for every visible item.
