# caps

Claude Code plugins.

| Plugin | What it does |
|---|---|
| [interactive-html-deck](plugins/interactive-html-deck) | Builds presentations as one self-contained HTML file: a 16:9 stage with step builds, animated diagrams, speaker notes and a check of every slide |

Install in Claude Code:

```
/plugin marketplace add devops01ua/caps
/plugin install interactive-html-deck@caps
```
